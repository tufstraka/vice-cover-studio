Vice Cover Studio turns a person's own photos into a GTA-6-style ensemble crime poster: eight cast panels around a hero close-up, gold chrome lettering with a script subtitle, role tabs, tagline ribbon, billing block, barcode and a gold seal, graded in five film looks and exported at 1080x1080, 1080x1350 and 1920x1080. Everything runs offline in desktop Chrome from `app/`'s own files; photos never leave the device.

## Run it

```sh
node serve.ts
# open http://localhost:8080
# or build the entry's dossier:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
